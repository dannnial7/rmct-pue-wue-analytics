System Overview

An Analytics Dashboard for Optimizing Power and Water Usage Effectiveness in Tropical Data Centers
Muhammad Danial Fitri bin Mohd Khairizal

Introduction

The proposed system is a web-based analytics platform designed to solve a critical visibility gap in tropical data center management. In hot and humid climates, disparate cooling systems lack unified monitoring, leading to undetected resource waste.

This system provides facility managers with a centralized dashboard that correlates vital power and water metrics against specific environmental constraints, offering actionable insights that traditional monitoring siloes miss.

System Architecture Flow

The dashboard operates on a lightweight, data-ingestion model designed for ease of deployment. The logic flow can be visualized as a structured pipeline. For this research, the system will ingest structured simulated datasets to prove the analytics engine's logic.

Core Functionality: Metric Calculation

The primary purpose of the Analytics Engine is to continuously calculate and monitor two established sustainability metrics using standardized industry formulas.

⚡ Power Usage Effectiveness (PUE)

Measures how efficiently a computer data center uses energy.

PUE = Total Facility Energy / IT Equipment Energy

In the simulation, Total Energy will be (IT Equipment + HVAC Power draw).

💧 Water Usage Effectiveness (WUE)

Measures the sustainability of data center water consumption, critical for cooling in humid regions.

WUE = Annual Site Water Usage / IT Equipment Energy

In the simulation, this will be modeled per minute of operation.

Key Dashboard Features

The user interface (Java-based frontend, potentially backed by SAS analytics processing) will offer the following capabilities:

  • Real-time Metric Visualization: Dynamic charts and gauges displaying calculated PUE and WUE values in real-time.
  • Dynamic Threshold Alerts: If calculated metrics exceed predefined thresholds (modeled for tropical operating constraints), the interface triggers visual alerts for facility managers.
  • Heatmap Overlays: (Optional enhancement) If simulation data allows, visualization of server rack temperatures to identify localized hot spots.
  • Historical Inefficiency Logging: Automated logging of alert events for later review and performance optimization.
